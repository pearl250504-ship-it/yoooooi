# 금기의 서재

세 작품을 읽고 학습하는 반응형 웹앱입니다.

## 포함 기능
- 시작 화면과 5권의 책이 꽂힌 책장
- 세 작품의 요약·내용을 2~3문장 단위로 넘겨 읽는 독서 화면
- 작품별 객관식 퀴즈(5문제/8문제)와 결과·해설
- 작품별 해설집
- 별도 서버 없이 실행 가능한 단일 HTML 앱

## GitHub Pages 배포
1. 이 압축 파일을 풀고 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고 `main` 브랜치, `/(root)`를 지정한 뒤 저장합니다.
4. 잠시 기다리면 `https://사용자이름.github.io/저장소이름/` 형태의 실행 주소가 생성됩니다.

## 바로 실행
`index.html` 파일을 브라우저에서 열면 실행됩니다. 인터넷 연결이나 별도 설치가 필요하지 않습니다.

※ 작품 내용은 학습을 위한 요약·재구성입니다. 원작 문장을 그대로 옮긴 것이 아닙니다.


## V4 개선 사항
- 시작 화면은 제목과 터치 버튼만 표시합니다.
- 독서 화면은 작품 내용만 표시하며, 앞장/뒷장 버튼과 좌우 스와이프로 이동합니다.
- 작품 해설은 해설집에만 표시합니다.
- 퀴즈 문항 수를 숫자 키패드로 1~8 사이에서 직접 입력합니다.
- 모바일 터치 하이라이트와 불필요한 자동완성 힌트를 제거했습니다.

## V3 개선 사항
- 화면 폭과 기기 크기에 맞춰 책장·독서·퀴즈·해설 화면의 여백과 글자 크기를 정돈했습니다.
- 독서 화면은 화면 높이에 맞춰 문장 단위로 페이지를 자동 구성합니다. 문장 중간에서 페이지가 끊기지 않도록 하고, 화면 크기 변경 시 페이지를 다시 나눕니다.
- 페이지 번호를 추가하고 이전/다음 이동 버튼의 간격과 크기를 통일했습니다.
- 모바일에서는 안전 영역을 반영하고, 버튼·패널의 모서리와 간격을 일관되게 조정했습니다.


## V4 변경 사항
- 독서 페이지는 문단 단위로 페이지를 구성하며, 한 문단이 화면보다 긴 경우에만 문장 경계에서 나눕니다.
- 책장 첫 번째 책의 제목 글자 크기를 자연스럽게 줄였습니다.
- 문제 수 입력 옆의 안내 문구를 '문제'로 간결하게 바꾸고, 9 이상 입력 시 안내창을 표시합니다.
- 독서 페이지 이동 버튼을 화살표만 표시하도록 정리했습니다.
- 퀴즈 풀이 화면에서 책장 바로가기와 작품 제목 표시를 제거했습니다.
- 퀴즈 해설과 해설집의 소주제를 별도 영역으로 구분하되, 본문 문장이나 단어를 임의로 강조하지 않습니다.


## V5 변경 사항
- 「황만근은 이렇게 말했다」 제목을 '황만근은'과 '이렇게 말했다' 두 세로 줄로 나누고, 기존 글자 크기는 유지한 채 책 표지 중앙에 배치했습니다.
- 문제 수 입력 옆 '문제' 글자를 더 키우고 굵기를 조정해 입력창 높이와 자연스럽게 어울리도록 했습니다.
- 독서 화면은 문단별로 페이지를 나눕니다. 일반 문단은 통째로 한 페이지에 표시하며, 화면보다 긴 문단만 약 3문장 단위로 나눕니다.


## 홈 화면 설치 안내 (PWA)
- GitHub 저장소의 최상위(root)에 `index.html`, `manifest.json`, `service-worker.js`, `icons` 폴더가 오도록 업로드합니다.
- GitHub Pages는 HTTPS로 배포해야 설치 기능이 동작합니다.
- Android Chrome: 배포 주소 접속 → 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
- iPad: Safari에서 배포 주소 접속 → 공유 버튼 → 홈 화면에 추가 → 추가. iPad Safari는 Android처럼 별도의 '앱 설치' 메뉴가 나타나지 않을 수 있습니다.
- 업데이트 후 이전 버전이 보이면 사이트를 새로고침하거나 홈 화면 바로가기를 다시 열어 주세요.
